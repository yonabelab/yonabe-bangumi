このページについて

確認日
「公式サイトで確認：10/31」は、その日に取得した作品の公式サイトの内容と照らして確かめた、という意味です。その後に配信先や開始日が変わっていることがあります。観る前に各配信サービスでもご確認ください。
「更新」の印
前回の確認から配信先が増えた、または配信開始日が変わった作品に、変わった日と一緒に付けます（直近2週間）。
「配信：確認中」
公式サイトで配信先をまだ確かめられていない作品です。推測では埋めていません。
データの出どころ
放送日時・放送局：しょぼいカレンダーのデータを使っています。
配信サービス・配信開始日：各作品の公式サイトを機械で読み取り、その結果を AI（Claude）が公式サイトの内容と照らして確認したものだけを載せています。人による確認はしていないため、誤りが残っていることがあります。出典のリンクは確かめたページです。
更新
週に1回。放送時間の変更（特番・休止など）がすぐには反映されないことがあります。

アクセス解析
ページの閲覧数を知るために、Cloudflare, Inc. の Cloudflare Web Analytics を使っています。ページを開いたときに、ページのアドレス、参照元、ブラウザの種類、表示にかかった時間などが Cloudflare に送られます。Cookie は使わず、個人を特定する情報は集めていません。検索や絞り込みの条件はこのページのアドレスに残ります。条件を付けたアドレスでページを開いたときは、その条件もアドレスの一部として送られます。条件を変えるたびに送ることはしていません。
